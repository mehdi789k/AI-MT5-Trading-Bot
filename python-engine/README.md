# MT5 AutoTrader — AI Trading Bot

ربات ترید خودکار متاتریدر 5 با مدل هوشمند پیش‌بینی‌کننده و قابلیت یادگیری از نتایج تریدهای قبلی.

## ساختار پروژه

این پروژه از سه بخش تشکیل شده است:

### 1. داشبورد وب (Web Dashboard)
داشبورد مدیریتی که در Bolt ساخته شده و برای کنترل و مانیتورینگ ربات استفاده می‌شود:
- صفحه اصلی: نمای کلی از وضعیت ربات، موجودی، سود/زیان
- پوزیشن‌های باز: مانیتور زنده با امکان بستن دستی
- تاریخچه ترید: لیست تریدهای بسته‌شده با فیلتر و آمار
- پیش‌بینی‌های هوشمند: جهت و میزان اطمینان مدل برای هر نماد
- یادگیری و عملکرد: نمودار بهبود دقت مدل و نتایج بک‌تست
- تنظیمات استراتژی: مدیریت نمادها، ریسک، حد ضرر/سود

### 2. پایگاه داده ابری (Supabase)
پل ارتباطی بین داشبورد و موتور ترید. تمام داده‌ها اینجا ذخیره می‌شوند:
- تنظیمات ربات و نمادها
- پوزیشن‌های باز و تاریخچه ترید
- داده‌های بازار و پیش‌بینی‌های مدل
- گزارش‌های یادگیری و لاگ‌ها

### 3. موتور ترید محلی (Python Engine)
اسکریپت پایتون که روی ویندوز شما کنار متاتریدر 5 اجرا می‌شود:
- به MT5 متصل می‌شود و بازار را می‌خواند
- پیش‌بینی‌های هوشمند تولید می‌کند
- سفارش‌ها را به‌صورت خودکار باز و بسته می‌کند
- از نتایج تریدها یاد می‌گیرد و مدل را بازآموزی می‌کند
- همه داده‌ها را به پایگاه داده ابری می‌فرستد

## راه‌اندازی موتور ترید روی ویندوز

### مرحله 1: نصب پیش‌نیازها

```bash
# مطمئن شوید پایتون 3.10+ نصب است
python --version

# نصب کتابخانه‌های موردنیاز
pip install MetaTrader5 requests numpy scikit-learn
```

یا با استفاده از فایل requirements:

```bash
pip install -r python-engine/requirements.txt
```

### مرحله 2: تنظیم config.json

فایل `python-engine/config.json` را با اطلاعات حساب دمو MT5 خود پر کنید:

```json
{
  "mt5": {
    "login": 12345678,
    "password": "your_demo_password",
    "server": "your_broker_demo_server",
    "terminal_path": "C:\\Program Files\\MetaTrader 5\\terminal64.exe"
  },
  "supabase": {
    "url": "your_supabase_url",
    "anon_key": "your_supabase_anon_key"
  },
  "engine": {
    "heartbeat_interval_sec": 5,
    "decision_interval_sec": 10,
    "prediction_interval_sec": 30,
    "retraining_interval_trades": 20,
    "min_confidence_threshold": 60,
    "min_trades_for_model": 10
  }
}
```

**نکات مهم:**
- `login`: شماره حساب دمو MT5 شما (عدد)
- `password`: رمز عبور حساب دمو
- `server`: نام سرور بروکر (مثلاً `MetaQuotes-Demo` یا نام سرور بروکر شما)
- `terminal_path`: مسیر فایل `terminal64.exe` متاتریدر 5 (معمولاً `C:\Program Files\MetaTrader 5\terminal64.exe`)
- مقادیر Supabase (`url` و `anon_key`) از فایل `.env` پروژه کپی کنید

### مرحله 3: اجرای موتور ترید

```bash
cd python-engine
python main.py
```

پس از اجرای موتور، داشبورد به‌صورت خودکار با مرورگر پیش‌فرض ویندوز در آدرس `http://localhost:5173` باز می‌شود. اگر می‌خواهید این رفتار را غیرفعال کنید، مقدار `dashboard.open_on_start` را در `config.json` روی `false` بگذارید.

اگر اتصال موفق باشد، پیام زیر را می‌بینید:
```
MT5 connected: Your Name | Balance: 10000.00 USD
Engine running. Press Ctrl+C to stop.
```

### مرحله 4: شروع ترید از داشبورد

1. داشبورد وب را در مرورگر باز کنید
2. مطمئن شوید که وضعیت ربات «Idle» یا «Running» است (یعنی موتور آنلاین است)
3. به صفحه **Strategy Settings** بروید و نمادها و تنظیمات ریسک را بررسی کنید
4. دکمه **Start Bot** را در نوار کناری بزنید
5. ربات شروع به تولید پیش‌بینی و ترید خودکار می‌کند

## نحوه عملکرد ربات

### چرخه تصمیم‌گیری
1. **خواندن بازار**: هر ۳۰ ثانیه، کندل‌ها و اندیکاتورهای نمادهای فعال را می‌خواند
2. **پیش‌بینی**: مدل هوشمند جهت قیمت (بالا/پایین/خنثی) و میزان اطمینان را پیش‌بینی می‌کند
3. **تصمیم ترید**: اگر اطمینان بالاتر از حد مشخص‌شده (پیش‌فرض ۶۰٪) باشد و جهت خنثی نباشد، سفارش باز می‌کند
4. **مدیریت ریسک**: حجم پوزیشن بر اساس درصد ریسک تعیین‌شده و فاصله حد ضرر محاسبه می‌شود
5. **مدیریت پوزیشن**: حد ضرر/سود متحرک (trailing stop) را مدیریت می‌کند

### حد ضرر/سود
- **حالت ثابت (Fixed)**: SL و TP بر اساس درصد مشخص‌شده از قیمت ورود محاسبه می‌شوند
- **حالت پویا (Dynamic)**: SL و TP بر اساس ضریب ATR (نوسان بازار) توسط مدل هوشمند تنظیم می‌شوند

### یادگیری خودکار
- پس از هر ۲۰ ترید بسته‌شده، مدل با داده‌های جدید بازآموزی می‌شود
- دقت مدل، نرخ برد و نتایج بک‌تست در داشبورد نمایش داده می‌شوند
- مدل با گذشت زمان و افزایش تعداد تریدها بهتر می‌شود

### پیش‌فرض‌های مدیریت ریسک
- حداکثر ریسک هر معامله: ۱٪ از موجودی
- حداکثر پوزیشن همزمان: ۵
- حداقل اطمینال مدل برای ترید: ۶۰٪
- هر نماد فقط یک پوزیشن همزمان

### مدیریت سرمایه و حفاظت از حساب
- **حالت ریسک هر معامله**: درصدی از موجودی (پیش‌فرض) یا مبلغ ثابت به ارز حساب
- **حد زیان روزانه**: اگر زیان امروز از این درصد بیشتر شود، معاملات جدید متوقف می‌شوند (زمان شروع روز با ساعت ریست قابل تنظیم است، به وقت UTC)
- **حداکثر دراداون**: اگر سرمایه از اوج خود به اندازه این درصد افت کند، ربات به حالت «متوقف» می‌رود تا خودتان ادامه دهید (دکمه ادامه ترید در تنظیمات)
- **حداکثر ریسک کل**: مجموع ریسک پوزیشن‌های باز (بر اساس فاصله حد ضرر) نباید از این درصد بیشتر شود

### سفارش‌های لیمیت (Limit Orders)
- برای هر نماد می‌توانید نوع سفارش را «لیمیت» انتخاب کنید (فعال‌سازی کلی از تنظیمات سرمایه)
- قیمت ورود لیمیت با فاصله‌ای از قیمت فعلی (ضریب ATR) ثبت می‌شود
- سفارش‌های معلق در داشبورد (صفحه پوزیشن‌ها) دیده می‌شوند و قابل لغو هستند
- سفارش‌هایی که در زمان مشخص منقضی شوند، توسط MT5 لغو می‌شوند

**همه این مقادیر از صفحه Strategy Settings در داشبورد قابل تغییر هستند.**

## هشدارها و نکات ایمنی

- **همیشه با حساب دمو شروع کنید** قبل از استفاده از حساب واقعی
- اطلاعات ورود MT5 فقط در فایل `config.json` روی کامپیوتر شما ذخیره می‌شود و هرگز به اینترنت ارسال نمی‌شود
- ربات فقط زمانی ترید می‌کند که دکمه **Start Bot** در داشبورد زده شده باشد
- می‌توانید هر زمان با زدن **Stop Bot** یا فشردن `Ctrl+C` در ترمینال، ربات را متوقف کنید
- بستن دستی یک پوزیشن از داشبورد درخواستی به موتور می‌فرستد که آن را در MT5 می‌بندد

## فایل‌های موتور ترید

```
python-engine/
├── main.py              # موتور اصلی ترید (اتصال MT5، اجرای سفارشات)
├── ai_model.py          # مدل هوشمند پیش‌بینی و یادگیری
├── indicators.py        # محاسبه اندیکاتورهای فنی (RSI, ATR, MACD, EMA)
├── supabase_client.py   # ارتباط با پایگاه داده ابری
├── config.json          # تنظیمات (اطلاعات MT5 و Supabase)
├── requirements.txt     # کتابخانه‌های موردنیاز پایتون
└── model.pkl            # مدل ذخیره‌شده (خودکار ساخته می‌شود)
```
